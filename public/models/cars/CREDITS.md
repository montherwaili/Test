# Car models

From the **Car Kit** (version 3.1) by Kenney, <https://kenney.nl/assets/car-kit>,
released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
(`License.txt`). No attribution is required; it is given here with thanks.

Converted to glTF JSON with the buffer inside (`<name>.json`, as some hosts will not serve `.glb`); the colour atlas is `colormap.png`. The game stretches each body to its own car's length,
wheelbase, width and height when it loads them (`src/render/kenneyCars.ts`).
